# Prompt Repetition Benchmark

Готовый комплект для парного A/B-эксперимента: влияет ли точное двукратное повторение пользовательского промпта на точность современной LLM.

## Что внутри

- `AGENT_PROMPT.md` — короткий промпт, который можно целиком передать coding-агенту.
- `EXPERIMENT_SPEC.md` — полный протокол, метрики, статистика и критерии готовности.
- `config.example.yaml` — конфигурация модели, API и бюджета.
- `data/tasks.jsonl` — замороженный набор из 220 автоматически проверяемых заданий:
  - 160 стресс-тестов на поиск элемента в длинном контексте;
  - 60 практических задач на русском.
- `templates/telegram_post.md` — пост, который агент должен заполнить реальными числами.
- `templates/report.md` — структура итогового отчёта.
- `schemas/` — схемы сырых прогонов и сводки.
- `scripts/validate_tasks.py` — проверка целостности датасета.
- `SHA256SUMS.txt` — контрольные суммы исходных файлов.

## Как использовать

1. Скопировать `config.example.yaml` в `config.yaml` и указать модель, endpoint и имя переменной с API-ключом.
2. Передать агенту файл `AGENT_PROMPT.md` вместе с этой папкой.
3. Агент должен не только написать код, но и выполнить прогон, сохранить сырые ответы, посчитать статистику и собрать финальный пост в `out/telegram_post_final.md`.

Основной источник: https://arxiv.org/abs/2512.14982

Вирусный пересказ, который разбирается в посте: https://blog.promptlayer.com/prompt-repetition-improves-llm-accuracy/
