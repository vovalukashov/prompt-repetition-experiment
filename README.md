# Prompt Repetition Benchmark

Парный A/B-эксперимент: влияет ли точное повторение пользовательского промпта
на точность современной LLM. Репликация ключевого утверждения препринта
[Prompt Repetition Improves Non-Reasoning LLMs](https://arxiv.org/abs/2512.14982)
на живых моделях, с сырыми логами всех запросов.

Разбор с методологией и интерпретацией:
[«Скопируй промпт дважды и получишь +76%». Я решил проверить](https://habr.com/ru/articles/1065930/)

## Результаты

Коротко: на задачах поиска элемента в длинном списке повтор дал +38,8 п.п.
при выключенном reasoning и +36,3 п.п. на минимальном уровне рассуждения,
а с включённым — 160/160 в обоих условиях, то есть чинить нечего. На обычных
задачах статистически ясного эффекта нет ни в одном прогоне.

Сводка по всем прогонам — [RESULTS.md](RESULTS.md). Полные отчёты, метрики,
графики и сырые ответы каждого прогона — в `out/<UTC_TIMESTAMP>*/`.

## Что внутри

- `EXPERIMENT_SPEC.md` — полный протокол: правила запросов, метрики,
  статистика, критерии готовности.
- `RUNBOOK.md` — как воспроизвести: установка, команды, режимы reasoning
  по моделям, ограничения.
- `config.yaml` / `config.example.yaml` — конфигурация моделей, API и бюджета.
- `data/tasks.jsonl` — замороженный набор из 220 автоматически проверяемых
  заданий: 160 стресс-тестов на поиск элемента в длинном контексте (EN/RU)
  и 60 практических задач на русском.
- `runner.py` — прогон: warm-up, пилот стабильности, парный A/B c retry-политикой.
- `scoring.py` — детерминированный парсинг ответов, точный тест Макнемара,
  парный bootstrap.
- `analyze.py`, `analyze_ablation.py` — метрики, графики и отчёты,
  пересчитываемые из сырых логов.
- `templates/report.md` — структура итогового отчёта.
- `schemas/` — схемы сырых прогонов и сводки.
- `scripts/validate_tasks.py` — проверка целостности датасета.
- `tests/` — тесты парсинга, статистики и конвейера отчётов.
- `SHA256SUMS.txt` — контрольные суммы исходных файлов.

## Как воспроизвести

Коротко (подробности в `RUNBOOK.md`):

```bash
python3 -m venv .venv && .venv/bin/pip install httpx pyyaml matplotlib numpy pytest
echo 'GOOGLE_GENERATIVE_AI_API_KEY=…' > .env
.venv/bin/python scripts/validate_tasks.py data/tasks.jsonl
.venv/bin/python -m pytest tests/ -q
.venv/bin/python runner.py            # standard preset, ~440 запросов, ~$0.02
.venv/bin/python analyze.py out/<STAMP>
```

Основной источник: https://arxiv.org/abs/2512.14982
